A Java desktop application built as a college project using Java and Swing.

Social_Connect simulates a small social messaging application with a graphical user interface, user-to-user messaging, photo handling and persistent data storage. The project was developed across the application rather than as a single isolated feature, with work covering the interface, program logic, data handling and testing.

Features

Swing-based graphical user interface

Simulated messaging between users

Photo and image handling

Persistent storage so application data can be retained between sessions

User-facing screens and application navigation

Input handling and validation

Testing and debugging across the application

Technologies

Java

Java Swing

Object-oriented programming

File/data persistence

Event-driven programming

What I worked on

The project involved building and connecting the different parts of a desktop application, including the Swing interface, messaging behaviour, photo handling and persistent storage. I also tested the application throughout development and fixed issues as the different features were brought together.

The project gave me practical experience working with a larger Java codebase and managing interactions between the user interface, application logic and stored data.

Running the project

Clone the repository:

git clone https://github.com/Taim-7/Social_Connect.git

Open the project in a Java IDE such as IntelliJ IDEA, Eclipse or NetBeans, then run the application's main class.

The exact Java version and launch class depend on the project configuration in the repository.
